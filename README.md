# 生成文件管家 2.1

按项目定位和管理 GPT / Codex、DeepSeek 保存在电脑上的文件。

[下载 Windows 桌面版](https://github.com/BoYu815/LibraryCleanerDesktop/releases/latest)

完整解压后打开 LibraryCleaner.exe。先完全退出旧版，保留 DLL、resources、locales 等配套文件。无需登录云端资料库。

## 本地文件与项目

打开后自动定位本机 AI 项目、会话输出和生成图片目录。顶部“全部 / GPT / DeepSeek”一键切换，左侧点击项目名称，右侧查看文件、真实路径、类型、大小和修改时间。可以搜索、筛选 PPT 等类型、打开文件或定位所在文件夹。

支持 CODEX_HOME、DSH_HOME、自定义数据目录与关联项目文件夹。普通下载明确列为待归类。依据项目登记和输出目录归属，不保证每个文件都是 AI 创建；未下载到本机的云端文件和其他电脑上的文件不在此范围。

## 右键删除这一项

右键具体项目或输出文件夹，选择“删除这一项…（保留 7 天）”。预览会显示真实路径、整个目录的文件数量，以及明确关联的对话列表。确认后统一处理所选项，不根据同名标题推测关联，也不扩大到其所属大项目。

整项目录操作会包含隐藏文件和子目录。含有其他独立项目、系统和账号数据、受管回收区或当前运行程序的范围会被拒绝；正在运行的已关联对话也会阻止整项处理。

## 回收区保留七天

删除文件或目录后先进入本工具的回收区，保留 7 天，期间点击左下角“回收区”可以恢复。原位置出现同名内容时拒绝覆盖。

到期内容会在软件运行时检查，或者在下次打开软件时自动清理。**不安装后台任务，软件关闭期间不会执行清理。**到期永久清理后不能再通过本工具恢复。

回收区统一显示和管理。文件尽量留在原磁盘的受管临时目录，以便原盘直接移动、避免大文件跨盘复制。恢复和到期清理只操作经过归属核对的记录，不清空 Windows 系统回收站。

原位置重新出现项目、对话恢复或变化、目录链接异常等情形会暂停到期处理，并在回收区显示原因，不会继续猜测或强行清理。

## 对话支持范围

| 平台 | 当前行为 |
| --- | --- |
| GPT / Codex | 只处理已确认归属的对话及其明确子对话；先归档，7 天内可恢复，到期才调用官方永久删除接口。原项目登记保留到到期处理，以便恢复。真实对话永久删除尚未实机验收，预览会注明。 |
| DeepSeek | 文件和目录支持回收区；可恢复的对话删除及到期永久删除接口尚未验证，因此对话删除禁用，不报告对话已删除。 |
| 无可靠归属的文件夹 | 仅处理文件，未确认的对话不动。 |

Codex 使用[官方 App Server 接口](https://learn.chatgpt.com/docs/app-server)的 thread/archive、thread/unarchive、thread/delete；官方永久删除会包含派生子对话，预览和复核会检查这些范围。归档不等于永久删除。

## 自动监测与边界

文件变化会自动更新，项目会定期重新核对。软件关闭后监测停止。大型目录分批显示进度，单个项目默认扫描上限 25,000 个文件；整目录删除预览另行核对全部内容，上限 100,000 项，超出时拒绝整项处理。默认不跟随目录链接。

待管理文件正文不被读取或上传；本地项目配置、回收记录和相关对话元数据保存在本机。程序未进行 Windows 代码签名。早期上游原包没有 LICENSE，来源说明见 THIRD_PARTY_NOTICES.md。

## 验证与开发

40 项自动测试（含历史回归）和最终 EXE 的 11 项桌面演示检查通过。覆盖路径移植、平台切换、文件监测、七天边界、重启后清理、整项恢复、同名冲突、目录链接攻击及对话范围变化。文件验证只使用新建临时文件，对话生命周期使用模拟接口；没有删除用户原有文件或对话。
