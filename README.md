# 生成文件管家 2.0

按项目查找和管理 GPT / Codex、DeepSeek 保存到电脑上的文件。

[下载 Windows 桌面版](https://github.com/BoYu815/LibraryCleanerDesktop/releases/latest)

解压后打开 `LibraryCleaner.exe`。请下载 **2.0.0 或更新版本**，保留 DLL、resources、locales 等配套文件。程序无需登录云端资料库。

## 如何使用

1. 打开后自动定位本机 AI 项目和输出目录。
2. 点击顶部 **GPT / DeepSeek**，切换对应平台。
3. 点击左侧项目名称，右侧查看所属文件、真实路径、类型、大小和修改时间。
4. 可以搜索文件、筛选 PPT 等类型，打开文件或打开所在位置。
5. 选中文件后点击“移到回收站”。确认后处理电脑上的实际文件，可通过 Windows 回收站恢复。

界面采用简洁的两栏布局，平台滑块和列表切换有轻量过渡动画。系统设置减少动画时会遵循该偏好。

## 自动定位与监测

- 从 GPT / Codex 的官方本机项目接口、项目登记和会话输出目录读取项目位置。
- 识别 GPT / Codex 的默认生成图片目录，并根据可用的本机会话归属关联到项目。
- 从 DeepSeek Harness 的工作区记录读取项目名称和真实目录，同时提供 DeepSeek 下载目录的待归类文件。
- 项目中的 output、outputs 等目录，按下一级文件夹名称分组，方便查找各项任务的结果。
- 使用当前 Windows 用户目录，支持 `CODEX_HOME`、`DSH_HOME`，不固定开发者的用户名、盘符或安装版本。
- 监测目录中的新增和修改，并定期重新核对项目。软件关闭后停止监测。
- 特殊保存位置可以在“连接设置”中选择数据目录，或点击左侧“＋”关联具体项目文件夹。

另一个电脑会定位那个电脑上已有的项目和文件；软件不会自动搬运原电脑上的文件。

## 文件归属与范围

本地文件没有统一的“AI 生成”标记。软件根据项目登记、会话输出目录和已知生成目录归类；**项目目录里原有的文件也可能列出**。普通下载目录明确标为待归类，不把所有下载都认作 AI 产物。

未保存到本机的云端附件和远端电脑上的文件不会出现在本地列表。项目聊天内容、上传附件与本地磁盘文件是不同对象。

默认跳过依赖、隐藏目录、日志等；不跟随目录链接。每个项目的扫描上限为 25,000 个文件，超出或无法读取时有扫描提示，可关联更具体的文件夹。大型工作区会分批显示扫描进度。

## 删除与数据

- 删除前核对文件身份和路径，修改过或位置变化的文件会被拒绝处理。
- 使用 Windows 原生回收站，不提供失败后永久删除的回退。
- 不递归删除目录，不删除原软件项目登记，不清理云端资料或聊天。
- 不读取待管理文件的正文，不上传文件内容。项目位置和连接设置仅保存在本机。
- 可执行文件的“打开”会定位到文件夹，不从列表直接运行软件或脚本。

## 验证与构建

已通过 28 项自动测试和最终 EXE 的 8 项桌面演示检查，包含不同用户路径、DeepSeek 项目、生成图片关联、目录链接保护、文件变化拒绝、实时新增文件和平台切换。Windows 回收站接口只使用新建的临时测试文件验证，没有删除用户原有文件。

需要 Windows x64、Node.js 24 与 npm：

```powershell
npm ci
node node_modules/electron/install.js
npm test
npm start
```

构建：`npm run dist -- --publish never`，输出为 `release/win-unpacked`。演示测试：`npm run smoke`，只操作独立临时测试资料。

程序未进行 Windows 代码签名。源代码保留早期云端版本的历史实现和回归测试；2.0 的实际入口是 `src/local-main.cjs`，安装包不加载旧云端管理页面。
