生成文件管家 2.0.0 · 本地项目文件管理版

下载 Windows x64 ZIP，完整解压后打开 LibraryCleaner.exe。请先完全退出旧版。

- 默认进入本地文件管理，不要求登录云端资料库。
- 一键切换 GPT / DeepSeek；点击项目名称查看文件、真实路径、类型、大小及修改时间。
- 按本机用户环境自动定位项目、会话输出与生成图片目录，支持自定义位置。
- 持续监测新增与修改，搜索和按 PPT 等文件类型筛选。
- 删除前核验目标，确认后移到 Windows 回收站，不递归删除项目目录。
- 简洁两栏界面，平台滑块与列表有轻量过渡动画。

定位根据本机登记和输出目录完成，不能保证每个列出的文件都是 AI 创建。下载目录单独标为待归类；未落到本机的云端文件不在此范围。

27 项自动测试和 8 项完整桌面演示检查通过。Windows 回收站仅用新建临时文件验证，没有删除用户原有文件。
