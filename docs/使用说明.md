## 桌面项目

点击顶部“桌面项目”。

- **ChatGPT / Codex 本地项目**：通过已安装官方程序的本机接口读取项目名称和关联目录。点击“从原软件移除”后，先出现确认弹窗，再调用官方接口并重新读取原始列表核验。原软件侧栏若仍保留旧画面，需要刷新原软件。
- **DeepSeek 桌面项目**：默认读取当前用户的工作区登记，未启用连接器时为只读。名称、目录和会话数量可以先查看。
- **ChatGPT 云端项目**：与本地项目分开。需要先在本工具内登录 ChatGPT；只有页面正常响应中包含可识别的项目列表时才显示。云端项目删除接口尚未验证，本版不提供删除。

“移除本地项目”指移除原软件的项目注册，不是清理硬盘目录，也不是永久删除所有聊天。DeepSeek 的关联聊天可能成为未分组会话。每次操作前请检查弹窗中的名称、平台和影响范围。

## 第一次连接 DeepSeek

1. 点击“启用 DeepSeek 连接”。
2. 阅读确认弹窗。连接器仅提供本机项目列表和项目注册移除，不读取聊天正文或账号密钥。
3. 确认后，程序会备份并追加 DeepSeek 桌面配置中的一条插件声明。
4. 重新打开 DeepSeek Harness，再在本工具里点击“刷新列表”。连接成功后才能执行项目移除。

连接器使用本机命名管道，不开放网络监听端口。它调用 DeepSeek 原有的工作区接口，不直接修改项目数据库。真实 DeepSeek 宿主加载后的端到端移除仍需在用户启用后验收；开发阶段没有安装到用户的真实配置，也没有移除用户现有项目。

## 别人的电脑或自定义路径

程序不会把开发电脑的用户名、项目路径或安装版本写死到运行代码中：

- 按当前 Windows 用户定位默认 `.codex`、`.dsh` 数据目录。
- 尊重当前环境中配置的 `CODEX_HOME`、`DSH_HOME`。
- 自动查找微软商店安装的 ChatGPT/Codex 官方项目接口；部分独立安装位置也会尝试定位。
- 项目实际关联目录来自各平台项目记录，不靠扫描固定磁盘猜测。
- 自动定位失败时，展开“连接设置”，选择官方 `codex.exe` 或实际的数据目录。
- 自定义设置只保存在本机本工具的数据目录里，不移动原软件的数据。
- 多个 DeepSeek 数据目录的连接器按目录分别隔离，避免连错资料。

项目记录可能指向已经不存在的目录。界面显示登记的路径，不代表目录存在，也不会自动重新创建或删除目录。

## 原有文件库功能

ChatGPT 文件库的同步、筛选、日期清理、ZIP 备份和确认删除继续保留。首次使用需在窗口中自行登录。备份正在下载或保存时，删除操作会被阻止。

本版新增的是 DeepSeek **桌面项目管理**；DeepSeek 上传附件的独立文件库清理尚未实现，不能把项目移除当作附件清理。

## 验证与限制

- 已通过 18 组自动策略测试：来源限制、精确项目身份、变更核验、只读回退、连接器授权、配置备份、跨用户定位和中文路径保存等。
- 用官方接口创建并移除了一个临时测试项目；核验原项目仍在，本地测试文件保留。
- 已只读核对本机实际的 ChatGPT/Codex 和 DeepSeek 项目记录，没有移除用户项目。
- 完整演示测试使用虚构项目和虚构文件，不代表真实账号登录及接口永远兼容。
- DeepSeek 连接器需要安装后重启宿主；ChatGPT 云端项目读取需要用户登录并返回可识别响应。
- 程序未进行 Windows 代码签名。来源、第三方权利和原扩展说明见随附文档。

后续版本如需删除聊天、删除云端项目或删除本地目录，应分别明确设计和验证，不能通过现有“移除项目”按钮隐含执行。
