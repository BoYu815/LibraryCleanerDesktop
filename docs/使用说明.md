# 生成文件管家 2.0 使用说明

先完全退出旧版，解压后打开 LibraryCleaner.exe。保留完整解压目录，不要只复制 EXE。

## 按项目找文件

打开软件后会自动定位 GPT / Codex 与 DeepSeek Harness 的本机项目。顶部“全部 / GPT / DeepSeek”可以一键切换。左侧点击项目名，右侧列出文件及其真实路径。

支持搜索文件名和路径，按演示文稿、文档、表格、图片、软件压缩包等类型筛选。项目下常见的 output、outputs、artifacts 等输出文件夹会再按文件夹名称分组。点击“位置”可在资源管理器中选中文件。

软件运行期间会监测文件变化，并定期核对项目。关闭软件后监测停止，不会安装后台服务。

## 另一台电脑如何定位

按当前 Windows 用户和 AI 软件保存的项目记录定位，不固定用户名或盘符；支持 CODEX_HOME 与 DSH_HOME。

自动识别依赖本机已有的项目和输出记录。记录缺失、版本格式变化或文件放在未登记位置时，在“连接设置”中选择真实数据目录，或点击左侧“＋”关联具体文件夹。

另一台电脑只能管理那台电脑已保存的文件，不会自动把这台电脑的文件传过去。

## 哪些文件会显示

软件根据项目目录、会话输出位置和已知的生成图片目录查找文件。项目中的其他文件也可能列出，不代表每个文件都由 AI 创建。普通下载与 DeepSeek 下载中的文件明确标为待归类。

只在云端、没有下载到本机的附件不会出现在列表中。默认不跟随目录链接，跳过依赖、隐藏目录和日志等。单个项目超过 25,000 个文件或无法访问时，底部会有扫描提示，可点击查看原因。

## 删除

可以逐个删除，也可勾选后批量移到回收站。确认弹窗中会显示具体路径。删除影响电脑上的实际文件；保留项目文件夹、项目登记和聊天记录，不清理云端资料。

处理前再次核对文件和路径；变化过的文件需要重新扫描后选择。回收站操作失败时会提示原因，不会改为永久删除。恢复文件请使用 Windows 回收站。
