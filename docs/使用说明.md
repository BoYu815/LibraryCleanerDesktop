# 生成文件管家 2.1 使用说明

先完全退出旧版，解压后打开 LibraryCleaner.exe，保留配套文件。

## 找文件

顶部选择 GPT 或 DeepSeek；左侧点击项目名称，右侧查看文件与真实路径。支持搜索、类型筛选、打开和定位。自动定位依赖本机项目登记与已知输出目录；其他位置可以自行关联文件夹。

## 删除与恢复

单个文件、批量文件可移入回收区。右键左侧具体项目或文件夹，可选择“删除这一项…（保留 7 天）”。先核对真实路径、目录全部文件数量和明确关联的对话，再确认。

所选目录含隐藏文件和子目录，也会一起移入回收区。不会根据名称相似而扩大到所属大项目，无法确认的对话不处理。

回收区统一保留 7 天。点击左下角“回收区”可看剩余时间和恢复按钮；原位置有同名内容时不会覆盖。文件优先留在原磁盘的受管位置，避免跨盘复制，不要手动移动这些临时目录。

满 7 天后，软件运行时检查清理；如果软件已经关闭，就在下次打开时处理。没有安装后台任务。到期永久清理不能恢复。

如果原项目位置出现新内容、关联对话在原软件中恢复或变化、存储位置不可访问，软件会暂停相应清理并显示原因，避免处理错误范围。

## 对话

GPT / Codex 只针对可靠确认归属的对话，先归档，7 天内可以恢复，到期后才永久删除明确范围。原工作区登记在保留期内暂不永久移除。真实对话永久删除尚未完成实机验收，操作预览会提示。

DeepSeek 文件回收可以使用；对话的可恢复删除和永久删除接口尚未验证，因此本版不自动删除 DeepSeek 对话，也不会把归档冒充永久删除。

## 范围

另一台电脑只定位那台电脑已保存的文件，不会自动搬运旧电脑文件。普通下载和未知来源会标为待归类，项目中的原有文件也可能列出，不保证每个文件都由 AI 创建。

不要整项处理系统、账号数据或当前正在运行的软件目录；这些范围会被阻止。大型目录会显示扫描提示。未保存到本地的云端附件不在此工具范围。
